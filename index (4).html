How I build

  • Every state designed

    A screen isn't finished until the user can tell what is loading, what failed and what to do next.

  • Edge cases first

    Long text, repeated clicks, missing images and late data get checked before I call a feature done.

  • Performance you can feel

    Lighter images, fewer requests and fewer re-renders make a page feel fast, not only look right.

  • Requirements before code

    Understanding what is being asked, before writing anything, saves hours of rework later.
